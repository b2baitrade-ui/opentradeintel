# Roadmap

This roadmap communicates direction, not a delivery promise. Priorities may change based on maintainer capacity, user evidence, and contributor interest.

## v0.1

- JSON and CSV ingestion.
- Deterministic normalization and matching.
- Explainable scores through CLI and REST API.
- Docker, tests, CI, security policy, and contribution guidance.

## v0.2 candidates

- PDF text extraction and XLSX ingestion.
- Plugin-style connector discovery.
- Evaluated semantic matching as an optional complement to the baseline.
- A concrete, versioned MCP server package.

## v0.3 candidates

- Carefully maintained public procurement connectors.
- Public synthetic evaluation datasets and benchmark reports.
- Local embeddings and optional AI-assisted extraction.
- Regression fixtures for document parsers.

## Future exploration

- Community connector registry.
- Agent integrations and maintainer automation.
- Reproducible benchmark suite.
- More granular taxonomy and unit-conversion policies.
