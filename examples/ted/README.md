# TED public API example

`notice-search-response.json` is a trimmed public-data response derived from official TED notice [176184-2026](https://ted.europa.eu/en/notice/-/detail/176184-2026). It was retrieved through the official `POST /v3/notices/search` endpoint on 2026-08-24.

This file is public procurement data and is provided only to demonstrate the connector response shape. The supplier catalogs and benchmark records elsewhere in this repository are synthetic.

See [`docs/sources/ted.md`](../../docs/sources/ted.md) for API and reuse references.
